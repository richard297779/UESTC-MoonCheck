# 电脑蓝牙图形控制台

本工具通过电脑蓝牙控制 ESP32，复用 `ble_console.py` 协议；不依赖 Android APK，也不替代独立执行打卡的 `desktop/` 程序。

## 安装与双击启动

安装 Python 3.10+（Windows 安装器保留 Tcl/Tk 组件），在仓库根目录执行一次：

```powershell
python -m pip install -r tools/requirements-ble.txt
```

双击 [`tools/ble_console.pyw`](../tools/ble_console.pyw) 打开无终端窗口的 GUI。双击 [`tools/ble_console.py`](../tools/ble_console.py) 同样启动 GUI，但可能附带终端窗口。Windows 需要将 `.pyw` 关联到 Python；若没有反应或文件被编辑器打开，可右键“打开方式”选择对应环境的 `pythonw.exe`，勾选始终使用。终端中的 Python 与文件关联中的 Python 可能不同，请确保 bleak 安装在实际启动的环境中。也可执行：

```powershell
python tools/ble_console.py --gui
```

GUI 不自动安装依赖；缺少 bleak 时显示安装提示。Linux 需安装发行版的 tkinter、BlueZ，并具备蓝牙访问权限。macOS 需允许运行脚本的 Python/终端访问蓝牙。跨平台实机蓝牙兼容性仍待验证。

## 使用流程

1. 开启电脑蓝牙，让开发板上电，断开 APK 或其他 BLE 工具。
2. 扫描、核对广播名与地址、选择设备并连接；握手成功后才可操作。
3. 在分类页选择功能，填写表单，点击“执行 / 保存”。网络名和密码中的空格会原样保留。
4. 依次配置 Wi-Fi、账号、位置和本人微信授权；多人槽位按账号顺序使用 0–5。
5. 查看状态、前置体检与微信授权状态，再按需测试取票或执行打卡。页面内“帮助”提供离线命令指南。

分类页提供状态/时间/日志、Wi-Fi 扫描配置、账号增删与开关、位置、微信凭据导入与取票、调度、多账号执行、通知通道管理、SESSION 与恢复出厂。高级 JSON 页覆盖协议扩展操作，例如为新增账号同时指定独立坐标；字段格式见[命令参考](commands.md)。

设备概览展示设备运行信息，包括固件提供的网络名、内部堆峰值和 PSRAM 状态。按钮发送后等待相同请求 ID 的成功或失败回执，期间不接受重复操作。普通操作等待约 90 秒，全链路等待额外加上指定放行时间；多人或慢网络操作可能超时。超时表示结果未知，应查询状态与日志后决定下一步，程序不会自动重放命令。

## 隐私与操作提示

默认显示“设备概览”“我的账号”和分类设置。“我的账号”直接展示脱敏学号、启用状态和最近结果。连接后自动查询状态、账号、微信授权和通知配置，保存配置后重新读取；手动“刷新设备数据”可获取其他客户端的修改。设置页使用设备已返回的值；密码、令牌及设备未提供的字段不会回填。未提交的编辑不会被后台刷新覆盖。当前固件未在摘要提供窗口起点，留空表示保留原值。

密码和令牌输入隐藏，发送后清空，不保存至磁盘；切换功能也会清空当前表单。“查询结果”以字段名称与列表展示查询内容。完整协议回执、高级 JSON、设备日志与会话调试默认隐藏，仅勾选“开发者选项”后出现。完整回执仅在开发者模式收集，按敏感字段脱敏，仅保留在内存、限制约 500 行，关闭开发者模式或断开后清空。同时过滤常见凭据键、URL 与当前连接已发送的敏感值；未知格式的自由文本仍不能保证完全识别，分享前需自行检查。

打卡、真实通知、登录测试、自动调度开关、删除及恢复出厂会提示确认。保存只以设备回执为准；恢复出厂会使设备重启，可能来不及收到完整回执。断线后需手动重连，不自动重放配置或打卡。

连接失败先关闭其他 BLE 客户端、删除系统旧配对记录、开关蓝牙并靠近开发板；仍失败时用 APK 交叉验证。

## 命令行兼容与验证

无参数运行现改为 GUI。原命令行使用 `--cli`，已有带参数命令保持不变：

```powershell
python tools/ble_console.py --cli
python tools/ble_console.py --list
python tools/ble_console.py --name WANAN-XXXX hello status
python -m unittest discover -s tools/tests -v
```

自动测试覆盖表单类型与范围、旧设备长度限制、握手协商、回执匹配、失败/超时/断线和所有分类表单渲染；不访问真实设备或账号。GUI BLE 联调仍需用户实机验证，不沿用 APK 的联调结论。本工具随 [desktop-v1.1.0 电脑端预发行版](https://github.com/richard297779/UESTC-MoonCheck/releases/tag/desktop-v1.1.0) 提供源码 ZIP；运行需 Python、tkinter、bleak，建议配合固件 0.7.0。固件/APK 版本不变。
