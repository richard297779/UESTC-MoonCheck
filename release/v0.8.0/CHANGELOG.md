# MoonCheck 0.8.0：账号管理与双端蓝牙中控

- 电脑端四栏目：设备概览表格、九列账号表、统一查询与配置、开发者完整回执；普通界面完整显示学号，秘密和日志保持脱敏。

- 新固件在编译阶段映射本机路径；新资产独立检查隐私，历史二进制与标签保持不变。
- 发行新增独立 BLE 控制台源码 ZIP 与内部逐文件校验，整包包含六板型固件、Android Debug APK、电脑 BLE 源码和使用指南。
