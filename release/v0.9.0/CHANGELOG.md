# MoonCheck v0.9.0 小组确认

2026-11-26 本地验证版。固件、Android 控制端与电脑 BLE 控制台源码统一为 0.9.0。Android versionCode 为 900，使用原 Debug 签名。独立 Windows 桌面版使用 1.2.0。

- 复用门户登录会话，校验安全员账号及权限，读取当天的完整待确认名单。
- 批量确认符合条件的记录，保留平台标记异常或待人工处理的记录。提交后复查名单与计数。
- 小组模式需显式启用。固件用 BLE 控制台 `group on`，桌面在「打卡时间」页勾选「安全员小组确认」。调度沿用已有时间设置。

同板型且分区表一致时，解压对应的 full.zip，仅将 firmware.bin 写入 `0x10000` 以保留配置。首次安装使用该板型的 merged.bin 写入 `0x0`，会清空配置。升级后先用 `status` 确认版本和模式，再用 `login`、`probe` 查安全员会话与待确认人数。

v0.9.0 的真实账号提交、BLE 联调及硬件验证由使用者确认。异常情况请在自动任务前到网页上报，或先暂停当次运行。
