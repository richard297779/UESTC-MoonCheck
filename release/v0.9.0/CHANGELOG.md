# MoonCheck v0.9.0 小组确认

## 本版变化

适配新版「晚安成电」安全员小组确认。固件、Android 控制端和电脑 BLE 控制台源码统一为 0.9.0。Android versionCode 为 900，沿用原 Debug 签名。

- 复用门户登录会话，校验安全员账号及权限，读取当天的完整待确认名单。
- 修复身份接口用业务码 5000 返回「未登录」时提前退出的问题。小组账户按原有窗口策略建立会话后再核验身份。
- 批量确认符合条件的记录，保留平台标记异常或待人工处理的记录。提交后复查名单与计数。
- 各账户独立选择小组模式或个人定位模式。新账户默认使用小组模式，已有账户升级时继承原模式。同一设备可混合运行两种模式。
- 电脑 BLE 控制台将设置整理为「账户配置」「今日打卡」「计划与通知」「设备与诊断」。账户列表显示完整学号，密码和 32 位浏览器指纹以掩码输入。编辑时留空可保留已有凭据。

## 升级与验收

同板型且分区表一致时，解压对应的 full.zip，仅将 firmware.bin 写入 `0x10000` 以保留配置。首次安装使用该板型的 merged.bin 写入 `0x0`，会清空配置。升级后先确认版本和模式，再执行登录检查和前置体检。命令行可用 `group status`、`login`、`probe` 检查。

用户确认 ESP32-S3-N16R8 已成功配置并完成真实打卡。ESP32-WROOM-32 通过构建和镜像校验，v0.9.0 实机仍待验证。WROVER-4MB、S3-N8、S3-N8R8 和 C3-DevKitM-1 为实验目标，可自行构建。配置保留升级和其他设备组合仍待验证。

本版提供上述两种常规板型固件、Android Debug APK 和电脑 BLE 控制台源码。独立 Windows 桌面版 1.2.0 单独维护。本机已验证其真实账号的小组登录和待确认人数查询，桌面真实打卡提交待验证。

有组员联系不上时，请在自动任务前到网页上报异常，或暂停当次运行。
