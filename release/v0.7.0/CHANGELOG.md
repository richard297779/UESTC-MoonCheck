# v0.7.0 · 多板型与运行状态（Latest）

- 2026-10-27 修复固件 status 序列化覆盖已有 JSON 前缀，导致 APK 连接报回执不完整；生产组包与 APK 握手分片回归已补充。用户于 2026-10-27 确认修正版实测可行，更新固件即可。
- 新增 WROVER-4MB、S3-N8、S3-N8R8、C3-DevKitM-1 独立实验构建，保留 S3-N16R8 与 WROOM-32。
- APK 新增实际联网名称、IP、信号、内存使用峰值、最低可用堆、最大连续块、PSRAM、运行时长和网络任务栈余量。
- 开发者选项支持手动读取最近 30 行脱敏日志；不持久化、不导出，离开页面或断开连接清空。
- 单核任务绑定、LED 配置与极性适配；发行目录与实际构建元数据交叉核对，验证芯片、分区、OTA 容量及哈希。
- 版本统一 0.7.0 / Android versionCode 700；BLE 协议仍为 1，旧固件缺失指标显示未知。

维护者只能实测 ESP32-S3-N16R8 与 ESP-WROOM-32，本次实测未指明具体板型；其他四种型号**未经实际验证**，欢迎按[板型支持矩阵](../../docs/board-support.md)提供社区验证信息。v0.6.0 既有实测结论不沿用到新版本。

本版发布六板型固件、Debug 签名 APK、整套 ZIP 与 SHA-256 清单；原 v0.6.0 标签及资产不变。构建结果与验证限制见[项目体检](../../docs/project-health.md)。
