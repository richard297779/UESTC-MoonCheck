## 维护规则

1. 同一版本的 APK、merged/full 固件、PACKAGE、manifest 和摘要放在同一个版本目录，文件名保持版本及板型信息。
2. 不重命名包内文件、不重写历史 ZIP/二进制、不为缺失的历史清单补造发行证据。迁移时仅移动外部路径；原摘要仍按其所在目录中的文件名校验。
3. 解压副本放 `vX.Y.Z/extracted/<板型>/`；其内容不自动加入后续发行包。不能确定来源时先核对固件与原 ZIP，不猜版本。
4. 打包脚本使用显式资产清单，`.staging/`、解压副本、截图及 CHANGELOG 不会因整个文件夹打包而被意外加入。
5. `.gitignore` 仅保留迁移前已跟踪文件在新路径的追踪资格；新 APK、固件、暂存目录、密钥和 SDK 继续忽略。Git 干净克隆不一定含上述全部本机产物。
