## 已实施

- 电脑端入口保持 `ble_console.pyw` / 无参数 `ble_console.py`；新增 `ble_dashboard.py` 与纯数据模型 `console_model.py`，共享原 BLE 工作线程。
- 设备概览、账号列表、查询与配置、开发者完整回执四栏目；账号九列表格完整显示学号，启用列可直接操作，表格横向滚动。上部表单独立滚动，下部固定结果表。
- 账号新建 / 合并修改，空项不发送；按序号、标签、学号唯一匹配。新建四项必填，经纬度成对，地址独立。
- 微信目标自动读取账号表并解析槽位；快照变化或改目标清理旧授权，扫码只填表。固件再次核对 revision / label / slot。
- 四种执行支持多选已启用账号；固件先验证整个目标名单，再逐人隔离会话、票据与位置，汇总每人结果，最后恢复运行上下文。取票按当前标签定位，重复学号不能默认为第一槽。
- Android 同步能力协商、快照、合并表单、微信目标与执行目标多选，继续使用适合手机的卡片布局。
- Wi-Fi 扫描 JSON 正确转义，完整保留同名及隐藏 AP；用户文档、离线帮助及 BLE 源码包清单同步。

## 用户确认与进一步实机验收

2026-10-29 用户对本轮基本功能确认通过，不沿用旧版结论，也不补造逐板型或逐项实测明细。下列内容作为扩展验收建议：

1. 新固件握手含 account-v2 / selected-execution；电脑和手机连接、断线清空、旧固件升级提示。
2. 新建账号；只改地址 / 密码时，其他秘密、位置和禁用状态保持；重启后回读确认。
3. 开另一客户端更改账号后，旧表单 / 二维码不能导入旧槽；改标签保留授权，改学号要求重新授权。
4. 删除账号后全部授权清除，剩余账号重新导入；模拟存储失败时账号表保持，允许部分已清理授权需重导。
5. 一个 / 几个账号分别登录、链路检查、演练，确认位置与授权归属；真实打卡和通知仅由用户明确选择执行。
6. Wi-Fi 引号 / 中文 / 同名 / 隐藏网络全部展示；大字体、缩放和小窗口下结果区与按钮可用。

代理自动检查未操作真实扫码、账号登录、通知、打卡或刷板；用户基本功能确认单独作为验收来源。存储故障注入、运行时内存压测、跨平台与逐项扫码闭环没有详细实测证据。配对加密 / 设备鉴权未在本轮新增。
