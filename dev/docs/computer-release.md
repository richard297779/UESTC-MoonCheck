# MoonCheck Desktop 1.1.0 与电脑 BLE GUI 预发行

本轮以独立标签 `desktop-v1.1.0` 发布。固件 / Android 仍为 0.7.0，既有标签、资产和 Latest 标记保持不变。桌面程序和 BLE GUI 尚未完成真实账号 / 设备联调，使用 GitHub Prerelease，不把旧版实测结论视为本版验收。

## 下载选择

| 资产 | 用途与环境 |
| --- | --- |
| MoonCheck-Desktop-1.1.0-windows.zip | Windows x86-64 独立程序；解压后运行 MoonCheck.exe，无需安装 Python，不依赖 ESP32 |
| MoonCheck-BLE-Console-1.1.0-source.zip | BLE 图形控制台源码；需 Python 3.10+、tkinter、bleak，通过蓝牙配置 ESP32 |
| computer-release-manifest.json | 来源提交、验证边界、资产大小及 SHA-256 |
| sha256.txt | 两个 ZIP 和发行清单的 SHA-256 |

桌面新增每账号微信授权、刷新凭据原子保存、MMTLS / P-256 / AES-GCM、两次独立 code 和平台取票，再携票据提交；票据失败不自动重放。GUI / CLI 共享业务，提供跨进程锁与 UTC+8 窗口控制。Windows 程序未做生产代码签名，Linux 未构建。

BLE GUI 支持双击 pyw、设备概览、脱敏账号表、配置查询回填、编辑保护与分类按键；完整回执、日志、原始 JSON 位于默认隐藏的开发者选项。旧命令行通过 --cli 或带参数调用。恢复出厂、提交、真实通知等操作保留确认。设备未提供的配置不作为已确认默认值；密码和令牌不回填。

## 文档核对与隐私处理

- 核对桌面 / BLE 帮助、命令解析、固件实际字段与用户文档；修复 account add 的可选指纹参数、通知 URL 留空保留设备配置等不一致。
- 桌面日志隐藏 HTTP 路径、查询参数、Location 跳转票据；不回显非 JSON 错误正文。config show --all 兼容参数仍脱敏，不再提供敏感值直出。
- 导出递归清空学号、坐标 / 地址、历史消息、密码、会话、指纹、微信授权、票据和通知 URL；不修改真实运行配置。脱敏副本不是可直接运行的账号备份。
- BLE 按敏感字段、常见凭据文本和当前连接已发送的敏感值过滤回执。默认不收集完整回执，关闭开发者选项 / 断开时清空。不保证识别任意格式的个人自由文本，分享前仍需检查。
- 移除公开工程指南内的私人工作空间页面 ID；保留公开协议常量、服务器公钥、占位符与合成测试向量，不把它们误删为用户凭据。
- 本轮产物按白名单打包，不包含 config.json、签名私钥、HAR、构建日志、SDK 或依赖缓存；源码、ZIP 与冻结 Python 模块分别检查。

历史已跟踪固件二进制保留编译路径元数据，未改写历史或既有 GitHub 资产，本轮不分发这些文件。旧固件中的 PRIVATE KEY 字符串为 TLS 解析器标记（紧接 NUL），扫描未发现完整私钥 PEM。此处记录检查范围与已发现情况，不是对所有历史和未知格式作无泄露保证。

## 验证与限制

本轮运行桌面 55 项与工具 27 项测试，涵盖协议黄金向量、票据隔离、失效不重放、进程锁、GUI、脱敏导出、HTTP 跳转日志、BLE UTF-8 分片、回执 ID、断线 / 超时、配置回填及编辑保护。测试不连接真实设备或账号。

Windows 构建后执行版本、加密 selftest、dry-run、wx status 四个冻结程序冒烟命令。包装校验 PE / CLI 版本、源文件新鲜度与摘要、清单来源为干净 HEAD、ZIP 内容白名单及 SHA-256。GitHub 草稿上传后逐项核对远端资产大小和 digest，再公开。

真实桌面微信取票 / 打卡、GUI BLE 联调、Linux 构建和长期跨日运行仍待验证。新增四种实验 ESP32 型号仍未经实机验证；本轮未修改或重新构建固件 / APK，不新增硬件验收结论。反馈请提供系统、版本、复现步骤与脱敏错误。
