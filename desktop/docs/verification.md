# Desktop 1.1.0 验证记录

日期：2026-10-27。固件/Android 0.7.0 版本、标签与发行包不变；本次桌面独立版本为 1.1.0。实施计划见[移植计划](../../dev/docs/desktop-port-plan.md)。

## 已实现

每账号微信授权、签名 OAuth 刷新、旋转凭据原子保存、MMTLS/ECDH/Finished 校验、ManualAuth AES-192-GCM、PSK 0-RTT、小程序两 code/独立 Cookie 换票、带票据提交及失效停止重放。GUI 与 CLI 共享业务；新增授权页与 wx 命令、递归脱敏导出、跨进程锁、UTC+8 窗口及学号变更后清空旧授权。

## 自动验证

本次 **55 项测试全部通过，无跳过**；其中原有 23 项，新增协议/业务/并发/界面与隐私 32 项。14 个固件黄金输出参与逐字节对比；所有网络场景使用模拟传输。Windows PE 版本为 1.1.0.0，CLI 为 1.1.0。冻结程序的四个离线命令均返回 0。构建与冒烟使用项目内 TEMP，以适配当前宿主受限临时目录。

- 桌面测试覆盖原 AES、配置、Cookie、载荷与多账号通知；新增固件黄金向量、GCM 篡改、P-256、畸形帧/解压边界、分片 socket、模拟握手、ManualAuth、0-RTT、凭据旋转和按账号隔离。
- 平台票据前置条件、小程序 Cookie 与 CAS 隔离、两 code 不复用、4600x 不重放、CLI 导入/状态/清除、旧配置迁移、学号更换及进程锁均有回归。
- tkinter 使用隐藏窗口和临时配置验证授权页、隐藏输入、导入清空、脱敏导出，以及取票失败后回读已轮换凭据。不操纵用户正在使用的窗口，不使用真实账号。
- Windows PyInstaller 单文件构建，PE/CLI 版本与 desktop/VERSION 一致，打包包含 PyCryptodome 原生模块；冻结程序进行 --version、离线 selftest、dry-run 和 wx status 冒烟测试。

最终测试数量、产物大小与哈希以本次构建结果和 `desktop/dist/packages/` 的本地清单为准。

- 平台接口后续变化、实际网络代理与 HTTPDNS 可达性需用户验证。无需额外 YYB 服务，初次 QR 授权仍由本人准备。

## 用户实测顺序

先备份旧配置，运行 1.1.0；导入本人微信授权，点取票测试（不提交），核对账号与位置，再在允许窗口实际提交并复查。多人逐账号验证，最后测试通知和外部定时器。反馈时只提供版本、系统、步骤和脱敏错误，不发送密码、指纹、token、code 或票据。

本轮独立预发行补充：HTTP 日志隐藏路径、查询与 Location 票据；默认配置展示及 --all 均脱敏，导出进一步清除学号和位置。追加 4 项隐私回归。电脑 BLE 工具另有 27 项测试，见[发行说明](../../dev/docs/computer-release.md)。
